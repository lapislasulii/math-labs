# Линейная регрессия: влияние предобработки на обусловленность и качество

Задача — исследовать, как масштабирование признаков и полиномиальное расширение влияют на точность линейной регрессии и на числовую устойчивость решения.

## Метод

Регрессия решается методом наименьших квадратов через нормальные уравнения, без scikit-learn:

$$w^* = \arg\min_w \lVert Xw - y\rVert^2 \quad\Longleftrightarrow\quad X^TXw = X^Ty.$$

Вручную реализованы разбиение на обучающую и тестовую выборки, центрирование и нормировка признаков, генерация полиномиальных признаков, метрика MAE и подсчёт числа обусловленности $\operatorname{cond}(X^TX)$.

Данные: `housing.csv` (Boston Housing, 506 объектов, 13 признаков, целевая переменная — медианная стоимость жилья).

## Выводы

- **Масштабирование не меняет решение, но меняет обусловленность.** Для линейной модели со свободным членом центрирование и нормировка дают эквивалентную задачу, поэтому ошибки в экспериментах 1–4 совпадают. При этом число обусловленности падает на шесть порядков, и решение становится устойчивым к ошибкам округления.
- **Квадратичные признаки** улучшают качество на тесте (2.93 → 2.56), но $X^TX$ уже почти вырождена.
- **Кубические признаки** дают 559 признаков при 395 обучающих объектах: система недоопределена, модель интерполирует обучающую выборку (ошибка $\sim10^{-8}$) и полностью теряет обобщающую способность (ошибка на тесте 664). Число обусловленности $\sim10^{20}$ означает, что матрица численно вырождена.

> Датасет содержит признак `B`, построенный на расовом составе района; из-за этого Boston Housing исключён из scikit-learn. Здесь он оставлен для соответствия учебному заданию.
