# Сингулярное разложение изображения

Собственная реализация SVD двумя методами и её применение к сжатию и шумоподавлению изображения $1280 \times 922$ (каждый цветовой канал — отдельная матрица).

## Методы

**Степенной метод с дефляцией.** Для матрицы $A$ итерациями $v \leftarrow A^TAv / \lVert A^TAv\rVert$ находится старший правый сингулярный вектор, затем $\sigma = \lVert Av\rVert$, $u = Av/\sigma$, и из матрицы вычитается найденная компонента $\sigma uv^T$. Повторяется $k$ раз.

**Метод вращений Якоби.** К симметричной матрице $A^TA$ применяются вращения, обнуляющие максимальный внедиагональный элемент, пока он не станет мал относительно нормы Фробениуса. Сингулярные числа — корни из диагонали.

Для обоих методов выведены оценки числа арифметических операций, например для степенного метода

$$C_{\text{pow}} = k\,(2nm^2 + 2Nm^2 + 2nm) + 2knm.$$

## Результаты

**Точность.** Относительная ошибка восстановления $\lVert A - U_k\Sigma_kV_k^T\rVert / \lVert A\rVert$ при $k = 20$ — около 4% для всех каналов; уже 10 итераций степенного метода дают практически тот же результат, что и 100.

**Сравнение методов** (блок $200\times200$, эталон — `np.linalg.svd`): оба метода совпадают с эталоном в первых десяти сингулярных числах; степенной метод для $k = 30$ компонент работает примерно в 10 раз быстрее метода Якоби.

**Сжатие.** Хранение усечённого разложения требует $k(n + m + 1)$ чисел вместо $nm$:

| $k$ | Сжатие |
|---:|---:|
| 5 | 107× |
| 10 | 54× |
| 20 | 27× |
| 50 | 11× |

**Творческая часть.**
- Распределение яркости пикселей по каналам и то, как оно меняется после усечения разложения при разных $k$.
- Шумоподавление: к изображению добавляется гауссов шум ($\sigma = 30$), а низкоранговая аппроксимация отбрасывает младшие компоненты, в которых шум сосредоточен.
