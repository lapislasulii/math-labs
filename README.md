# math-labs

Учебные лабораторные по численным методам и математическому анализу (Университет ИТМО, «Инженерия искусственного интеллекта», 1 курс). Всё реализовано на NumPy, без готовых решателей из scikit-learn: методы написаны вручную и сверены с эталонными реализациями.

| Лабораторная | О чём | Ключевой результат |
|---|---|---|
| [Градиентный спуск](gradient-descent/) | Поиск локального минимума функции двух переменных, стратегии выбора шага и критерии остановки | Минимум найден с точностью $7\cdot10^{-5}$ по координатам и $8\cdot10^{-10}$ по значению; показано, почему критерий по $\lvert\Delta f\rvert$ даёт ложные остановки |
| [SVD изображения](svd-image/) | Степенной метод и метод вращений Якоби для сингулярного разложения; сжатие и шумоподавление картинки | Ранг 20 даёт относительную ошибку ≈ 4% при сжатии в 27 раз |
| [Линейная регрессия](linear-regression/) | МНК через нормальные уравнения, влияние масштабирования и полиномиальных признаков на обусловленность и качество | Стандартизация снижает $\operatorname{cond}(X^TX)$ с $2\cdot10^8$ до $\approx 97$; кубические признаки приводят к интерполяции и катастрофической ошибке на тесте |

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook
```

Каждая лабораторная лежит в своей папке вместе с данными; ноутбуки сохранены с результатами выполнения, поэтому графики и таблицы видны прямо на GitHub.
